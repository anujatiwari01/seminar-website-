Overview

This 5-day intensive seminar covers Cloud Computing and DevOps fundamentals with a focus on AWS. It includes theory + practical hands-on sessions like EC2 deployment, S3 storage, CI/CD pipeline, and monitoring.

Syllabus

Day 1: Cloud Foundations

  • Cloud basics, IaaS, PaaS, SaaS
  • AWS introduction & IAM

Day 2: AWS Core Services

  • EC2 (Compute)
  • S3 (Storage)
  • RDS & DynamoDB

Day 3: Networking & DevOps

  • VPC, Subnets, Security
  • DevOps lifecycle

Day 4: Git & CI/CD

  • Git & GitHub
  • CI/CD pipeline

Day 5: Monitoring & Project

  • CloudWatch
  • Cost optimization
  • Mini project deployment
